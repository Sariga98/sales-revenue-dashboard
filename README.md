# 📌 Project Overview

This project is an interactive **Sales & Revenue Dashboard** developed in **Microsoft Power BI** using the Sample Superstore dataset.

The dashboard transforms transactional sales data into meaningful business insights, enabling decision-makers to monitor performance, identify trends, evaluate profitability, and explore customer behavior through interactive visualizations.

---

# 🎯 Business Problem

Organizations generate large volumes of sales data, but extracting actionable insights can be challenging.

This dashboard answers important business questions such as:

- Which products generate the highest revenue?
- Which customers contribute the most profit?
- Which regions underperform?
- What are the monthly sales trends?
- Which product categories require strategic attention?
- How do discounts impact profitability?
